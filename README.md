## Getting Started

Follow these instructions to run the portfolio locally.

### Prerequisites

Install the following:
- Node.js (a version supported by the project's dependencies).
- npm.
- Git.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Shrikrishna2003/My-Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd My-Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local address displayed in your terminal, typically:

   `http://localhost:3000`

### Production Build

To check the production build:

```bash
npm run build
```

To run the production server after a successful build:

```bash
npm run start
```
